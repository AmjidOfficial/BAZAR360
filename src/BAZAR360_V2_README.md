# BAZAR360 V2 UI rebuild

The V2 visual layer is designed around four identities: Visitor, Registered User, Showroom Owner and Admin.

Use `src/styles/bazar360-v2.css` as the shared visual language for new and refactored surfaces.

### Product rule
Keep the experience as easy as a social feed. Advanced automotive tools should appear when needed, not all at once.

### Required surfaces
- Public home/feed
- Search and inventory
- Vehicle detail
- Showrooms hub and showroom storefront
- Visitor profile/login
- Registered user profile and dashboard
- Showroom owner dashboard and inventory management
- Admin dashboard and moderation
- Sell/Post flow
- Favorites, messages and notifications

### Visual rule
Premium through spacing, typography, media and motion. Avoid visual noise. 3D should add depth, not complexity.
